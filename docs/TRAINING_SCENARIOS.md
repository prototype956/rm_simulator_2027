# 训练出生场景

`daedalus_training` 和 `training_preview` 使用同一个 `PhysicalEnvironment::reset`。
当前 `sampling_revision=4`，相同版本、配置、资源、seed 和 scenario 参数复现同一初始状态。
revision 3 引入双方随机出生、中心能量机关及初始可见性检查；revision 4 恢复前哨站和
工程／中心兑矿区结构及其碰撞。新增遮挡可能改变同一个 seed 的出生位置或有效性。

## 场地和初始状态

训练加载 `GROUND.glb`、`POWER.glb`、`OUTPOST.glb`、`TECH_CORE.glb`、两辆车及原有标定板。
前哨站和工程／中心兑矿区以静态结构加载，参与出生避障、路径检查和视线遮挡。前哨站
复用正式装甲构建逻辑区分红蓝灯条及贴纸；不启用旋转和兑矿交互流程。中心能量机关作为静态未激活
障碍物，其底座和未激活靶面参与碰撞与遮挡；隐藏的激活状态替代模型不建立训练碰撞体。
训练不运行机关的随机方向、激活和旋转动画。第三辆英雄车仍不加载。

所有坐标使用 Bevy 世界坐标，Y 向上。红车 X/Z 在场地地面碰撞体的水平包围盒内采样，
边界向内缩一个车体包络半径；蓝车在红车周围按距离和方位采样。双方车体 yaw 独立均匀采样
于 [-π, π)，高度由地面支撑计算，包络底部距支撑面 5 mm。机关顶面不作为出生支撑面。
在模型和碰撞体就绪后摆放双方，再执行一次 1 ms 同步；不在旧原点进行物理沉降。
回合时钟随后归零，车辆在运行阶段仍沿用原有运动与战斗逻辑。

支撑检查包括中心和周边 8 个采样点：法线倾斜不超过 3°，地面高差不超过 3 mm。
圆柱包络与障碍物穿透大于 1 mm 时拒绝，双方也不能相交。平移目标整条路径每隔不超过
2 cm 检查支撑和障碍物，且全路径水平距离保持在 2–8 m。

## Reset 的 scenario 字段

| 字段 | 省略时行为 / 单位 |
| --- | --- |
| `controlled_position_xz_m` | 红车 X/Z 随机；可指定 `[x, z]`，单位米，Y 自动求解 |
| `controlled_yaw_rad` | 红车车体绕世界 +Y 的 yaw 随机，单位弧度 |
| `target_distance_m` | 两根节点水平距离在 [2, 8] 米采样 |
| `target_bearing_rad` | 蓝车出生方位在 [-π, π) 采样；0 沿世界 -Z，正值绕 +Y 转向 -X；与红车车体 yaw 无关 |
| `target_yaw_rad` | 蓝车车体绕世界 +Y 的 yaw 随机，单位弧度 |
| `gimbal_yaw_rad` | 云台世界 yaw 朝向蓝车，使用 ROS 云台约定，单位弧度 |
| `gimbal_pitch_rad` | 根据双方高度差朝向蓝车，正值向上，单位弧度，受配置机械限位约束 |
| `motion` | 默认 `{"kind":"static"}`；仍支持 `translation` / `rotation` |
| `measurements` | 默认关闭合成检测；不影响初始几何可见性检查 |
| `target_hp` | 默认目标预设；可覆盖整数 HP [1, 1000000] |

红车位置流、红车朝向流、蓝车距离流、方位流和朝向流相互独立。红车位置最多尝试 64 次，
红车确定后蓝车位置/路径最多尝试 64 次。显式指定红车位置时只检查该位置；同时指定蓝车
距离和方位时只检查该蓝车位置。不会改写显式参数以救活无效 seed。

## 初始可见性与无效 seed

完成姿态同步和云台初始化后，复用正式相机的外参公式、配置分辨率/FOV、GLB 装甲角点及
合成检测的几何判定。至少一块蓝车装甲必须同时满足：

- 外法线朝向相机（与视线方向点积至少 0.1）。
- 四个角点均位于相机前方、超过 0.1 m 近裁剪距离且落在图像边界内。
- 相机到装甲中心及四角的五条射线均无遮挡；端点前 1 cm 容差用于角点与碰撞皮肤的差异。

遮挡使用环境/装甲/战斗核心碰撞体近似，排除机器人根支撑圆柱与己方几何，与合成检测一致。
这是几何可见性要求，检测噪声、随机丢帧和延迟仍按 measurements 配置独立模拟。
初始云台的显式角度会被保留；未指定角度默认朝向蓝车，再执行上述实际光学检查。

合法位置生成后如果仍没有完整可见装甲，直接返回 `invalid seed ...`，不换一个位置或
暗中改变云台角度。地面/路径采样耗尽也返回无效 seed。训练客户端收到错误后应使用
**新 request_id** 发起另一个 Reset；旧失败请求重试只返回原缓存错误。失败期间禁止 Advance，
直到一次 Reset 成功。预览按 N/B 更换 seed，R 重试同一个 seed；无效时不显示上一回合车辆。

成功响应的 `data.evaluation.scenario` 包含实际双方位置/朝向、双方采样次数、被拒绝的
几何候选、初始云台角度和 `initial_visibility`。后者包含可见装甲数量、角点投影及遮挡原因。
这些是场景诊断真值，不是策略观测。视野保证仅针对 t=0，运动或控制后仍可能失去目标。
