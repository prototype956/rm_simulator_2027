# 多车型火控环境

本环境用于一对一自瞄选甲与开火。双方底盘和机构由场景脚本控制，敌方不主动射击；比赛角色与几何车型独立选择。训练服务器部署和网络结构不属于环境实现范围。

## 启动和配置

在 NUC 桌面终端进入 `/home/nuc/Workspace/bevy_robomaster_simulator`：

```bash
# 参数依次是己方角色、己方车型、敌方车型
bash scripts/run_multirobot.sh infantry wheel_leg standard
bash scripts/run_multirobot.sh sentry folding heavy_target
# 使用已有配置；相对路径相对于仿真仓库
bash scripts/run_multirobot.sh --config configs/rmul_2027_infantry.toml
```

启动脚本设置资产和动态库路径。多车型模式按角色生成临时配置，退出后删除；`--config` 模式保留原文件。`[combat]` 选择双方角色／资源，`[robots]` 选择车型。角色、车型和初始资源在 R 重置后生效；地图、资产重导入及程序升级需要退出后重启。

| 车型 | 资产与能力 |
|---|---|
| `standard` | 原步兵 GLB，正常驾驶与射击；不能通过低净空隧道 |
| `wheel_leg` | 用户 URDF，两条可动轮腿；200mm 举升、支撑转移及跳跃上台 |
| `low` | 重排原模型上装与底盘，保留原尺寸装甲；整机不超过 230mm，正常射击 |
| `folding` | 低底盘与收纳上装；折叠／展开各 0.8s，完全展开稳定 0.1s 后才可射击 |
| `heavy_target` | 仅敌方，HERO 几何近似、450HP、四块大装甲、无发射机构；不是旧英雄假人 |

前四种车型双方均可选步兵或哨兵。固定低矮与折叠稳定态保留隧道通行余量；230mm 是模型设计约束。折叠中、收纳态、展开中禁射；洞内展开或动作扫掠空间不足会拒绝。没有功率模型，血量／功率预设不改变车型几何。

## 操作

WASD 驾驶、方向键瞄准、空格射击、F3 切换视角、F5 切换自瞄、R 重置。自由相机模式下 WASD 控制相机。开启自瞄后由现有视觉链路控制云台。

Z 折叠／展开；X 轮腿举升／收腿，举升后向合法台阶驾驶；F6 独立跳跃。Alt+X／Alt+F6 控制当前敌方假人。C 保留假人云台控制，J 保留假人移动。轮腿完整操作见 [轮腿](WHEEL_LEG.md)。HUD 不写入训练图像。

## 训练与近似边界

图形与无渲染入口共用地图、车型、机构、战斗和遮挡逻辑。新多车型训练使用有限血量、热量和弹量，不自动补弹；目标击毁或己方死亡结束回合，己方耗尽弹量后结算在途弹再结束，默认 30s 时限由训练客户端截断。

策略仍负责选甲和开火，敌方车型、机构真值及未来轨迹只用于场景生成和评估；没有新增循环网络、观测／动作维度、奖励或自动课程。场景字段见 [训练场景](TRAINING_SCENARIOS.md)。

普通、低矮、折叠与重装采用分部结构碰撞代理，保留原装甲尺寸；轮腿使用分 CAD 零件／连杆凸包。小镂空、紧固件和轮胎接触属于近似。相机、枪口、装甲及碰撞共享实际挂点，装甲速度包含机构运动且不重复计入根运动。没有实车平衡、力矩、功率或完整六车比赛系统。

自动回归和资产检查通过 SSH 执行；驾驶、视角、机构按键与视觉手感由操作者在 NoMachine 中验收。旧版日志和命中数据不作为当前版本的验收结论。
