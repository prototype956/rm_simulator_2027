# 受限 Actor 与全局 Critic 输出

训练响应新增两个彼此独立的字段，原有评估数据继续保留：

- `actor_feedback.version=1`：已完成安装轴变换的理想 IMU（xyzw 姿态、机体系三轴角速度、时间戳/有效性）及 10 Hz 自身热量/允许发弹量/冷却增益反馈。热量采样复用裁判节拍；同一采样周期内不读取更实时的真值替换旧反馈。没有防御、HP、出弹、底盘、机构或综合开火许可字段。
- `privileged_state.version=1`：当前决策物理时刻的专用真值快照，包含双方位姿/速度、车体/枪口/装甲几何、资源/锁定、区域和冷却/防御计时、升降/折叠与已发机构请求、云台响应/排队命令、待完成射击请求及在途弹丸速度/寿命。没有场景随机种子、运动程序、未来命中或结算。

`src/training/observations.rs` 负责输出。IMU 使用每个固定物理步的安装姿态差计算机体系旋转向量速度；只有姿态和角速度送入 Actor 通道，位置不在其中。视觉帧仍携带用于调试的原几何数据，由新版视觉适配器在 PnP/EKF 之前清零导航平移。

冷却上限和基础速率来自本回合的资源配置。冷却增益只改变有效速率，反馈包含采样时的生效状态、剩余时间和有效速率。100 ms 采样间隔内保持上一份反馈；增益开始、刷新、结束时，状态、剩余时间和有效速率保持一致。防御规则保持现状，只向 Critic 暴露。

训练侧完整字段、归一化、掩码和部署契约见相邻 `rm_vision_rl/docs/asymmetric_observations.md`。本改动不改变 GUI、地图、比赛规则、固件或 IPC 共享内存 ABI；新字段在训练 JSON 协议中发布。
